# P1：老人核心数据

开发顺序：

```text
老人档案
 ↓
家属绑定
 ↓
照护人员
```

老人档案是整个系统的数据基础。

必须支持：

- 新增
- 编辑
- 查询
- 分页
- 状态
- 详情
- 病史
- 过敏史
- 紧急联系人
